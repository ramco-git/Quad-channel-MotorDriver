# クアッドチャンネルモータードライバ (超はんだもりもり森鴎外!）

クアッドチャネルのDCブラシ付きモータードライバ基板です。内臓MCUにSTM32F405RGT6を使用し、4つのエンコーダ入力と1つのUART、1つのclassic CANに対応しています。内部でのPID制御が可能です。エンコーダはインクリメンタル式にのみ対応し、ゼロ校正に必要なZ相を引き出しています。すべての通信線は5Vトレラントピンに接続されています。入力信号をダイオードによりミックスしているため、内部から、又は外部から直接PWMとDIR信号を入力して動作させることができます。

## 仕様
・MCUにSTM32F405RGT6を使用し、回転数、位置制御を基板単体で可能です。
| 機能 | 個数 | 備考 |
|-:|-|-|
| モータードライバ | 4 | 30V、連続10A(なお性能試験を行っていないため、詳細は不明) |
| モーター出力 | 4 | XT60PW-F |
| 電源入力 | 1 | XT60PW-M |
|　MCU | 1 | STM32F405RGT6 |
| ユーザーLED | 1 | RGBの一体型チップ |
| ユーザーボタン | 1 | CANのID設定などに使用 |

## 名前の由来
大電流に対応させるため、銅線をバスバーとして使用した。その結果、基板がはんだだらけになってしまった。「超」はんだもりもり森鷗外!が誕生した。
